# TGStat Prospecting — готовая справка по TGStat API для AI-агентов

> 🌐 [English version →](README.md)

**Дайте своему AI-агенту TGStat API — без галлюцинаций в эндпоинтах.**

Это готовая, адаптированная под агентов справка по TGStat API: точные эндпоинты, параметры, коды ошибок, лимиты и фолбэк-стратегии. Подгрузите её в Claude, Cursor, Hermes, Codex или Cline — и агент сразу знает, как искать, валидировать и извлекать контакты из Telegram-каналов. Без догадок и выдуманных URL.

## Какую проблему решает

Попросите агента «найти Telegram-каналы про X» — и он выдумает `channels/search` с неверными параметрами, словит `flood_control` или сожжёт квоту. Этот скилл даёт ему реальный API, чтобы он с первого раза вызвал нужное.

## Что получает агент

| Возможность | Точный метод |
|-------------|--------------|
| Поиск каналов | `channels/search` — ключ + страна (10 гео) + язык + поиск по описанию |
| Подписчики + описание | приходят сразу в ответе — без лишнего `channels/get` (экономит квоту) |
| Валидация жив/мёртв | HTTP `t.me/<username>` — сигналы `og:title` / `og:image` |
| Извлечение контактов | `t.me/s/<username>` — @упоминания + ссылки на ботов из ~20 постов |
| Контроль квоты | `usage/stat` — потраченные запросы, срок действия |
| Обработка ошибок | таблица: `flood_control_10/60`, `quota_*`, `outdated_statistics` и др. |
| Расширенный поиск | операторы `=`, `*`, `|`, `""`, `-`, `()` |

## Почему HTTP, а не клиентские библиотеки

`t.me/` и `t.me/s/` отдают публичные данные без авторизации. Клиентские библиотеки (Telethon и др.) при массовых запросах ловят FloodWait на часы. Этот скилл ведёт агента на публичные HTTP-эндпоинты — без аккаунта, без банов, без обхода ToS.

## Работает с любым агентом

- **Claude Code** — положите `SKILL.md` в каталог скиллов
- **Cursor** — добавьте как правило проекта / файл контекста
- **Hermes Agent** — `skill_manage(action='create')` с frontmatter из `SKILL.md`
- **Codex / Cline** — добавьте `SKILL.md` + `AGENTS.md` в репозиторий

## Быстрый старт (скрипты)

```bash
# 1. Поиск — подставьте ключи своей ниши в tgstat_search.py (помечено «ЗАМЕНИ»)
export TGSTAT_API_KEY=ваш_ключ OUT_FILE=channels.json
python3 scripts/tgstat_search.py

# 2. Валидация жив/мёртв
export SRC_FILE=channels.json OUT_FILE=live.json
python3 scripts/tgstat_validate_http.py

# 3. Извлечение ботов-контактов
export SRC_FILE=live.json OUT_FILE=contacts.json
python3 scripts/tgstat_extract_contacts.py
```

## Требования

- Python 3.8+ (для скриптов)
- TGStat API-токен (есть бесплатный тариф на [tgstat.ru](https://tgstat.ru))
- Только стандартная библиотека — `requests` опционально

## Безопасность

- Только публичные данные — без скрейпинга аккаунтов, без обхода ToS
- Исключать нелегальный контент (CSAM) — это уголовка в любой юрисдикции
- Параллелизм ≤8 потоков, чтобы не ловить ложные «мёртвые» каналы
